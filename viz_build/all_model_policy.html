4. 동일하게 둔 비교 예산과 남은 차이

  • 모델별·분할별 후보 4개를 선별 시드 2개로 평가하고, 가장 좋은 신규 후보를 동결한 뒤 기존 설정과 별도 시드 5개로 다시 비교합니다.
  • 선택 기준은 약전계 비율 증가 없음과 평균 RSRP 손실 ≤1 dB를 우선하고, 그 안에서 HO·핑퐁 감소의 동일 가중 평균을 봅니다. 평균 기준 개선 0.002 초과와 시드별 과반 승리가 있어야 교체합니다. 유의성 검정 결과는 아닙니다.
  • 후보 수와 학습 epoch가 같아도 CPU 시간·데이터 이용량은 다릅니다. 예측 결합은 예측기 학습이 추가되고, CQL은 고정 합성 버퍼를 쓰며, PPO는 새 행동을 샘플링합니다. 실행 시간과 학습 재생 행 수를 원자료에 기록하므로 모든 계산량을 완전히 같게 했다고 주장하지 않습니다.
  • 첫 공통 비교는 정해진 짧은 학습 예산의 비교입니다. 모든 모델이 수렴했거나 각 모델에 충분한 학습량이라고 확정하지 않았습니다. 이후 학습량 민감도도 별도 과제입니다.

6. 해석 범위와 근거

  • 새로 구성한 XGBoost·RNN·LSTM·GRU는 관측 서빙 신호의 10초 뒤 변화량을 예측합니다. 가상 정책이 유지한 셀의 미래를 직접 예측한 것은 아닙니다.
  • 예측 입력은 현재까지의 RSRP와 관측 동결 마스크입니다. 미래 값으로 앞부분을 채우지 않으며, 예측기 학습에는 해당 분할의 학습 세션만 사용합니다.
  • 기존 policy_v2의 외부 평가 세션은 여기서 평가하지 않고 수치를 고쳐 쓰지 않습니다. 재생 가정·강제 이동·샘플 간격·동일 단말/경로의 상관이라는 한계는 계속 남습니다.
  • 검증 개선과 시드 반복은 새로운 날짜·경로의 일반화 성능을 입증하지 않습니다. 별도 데이터와 고정된 최종 설계가 필요합니다.
  • 설정·분할·시드·모델 파일: outputs/all_model_policy/round_XXXX/plan.json, fold*_screening.json, fold*_frozen.json, fold*_confirmation.json, fold*.json. 예측기 캐시는 학습/검증 목록·설정·시드별로 분리했습니다.
