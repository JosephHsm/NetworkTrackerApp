선택 기준을 모델마다 바꾸지 않았습니다

검증 기준 망 대비 약전계 비율 증가가 없고, 평균 RSRP 손실이 1 dB 이하인 정책을 먼저 고릅니다. 그 안에서 0.5 × HO 감소율 + 0.5 × 핑퐁 감소율을 최대화합니다. 조건 충족 후보가 없으면 약전계 증가(%p)와 1 dB 초과 손실(dB)의 합이 최소인 후보를 택합니다. 서로 단위가 다른 위반량을 합산하는 이 규칙 자체도 연구자의 설계 선택입니다.

탐색 범위와 학습 예산

  • 규칙 27개/분할: 히스테리시스 {3, 6, 9} dB × 복귀 추가 문턱 {0, 3, 6} dB × A2 {없음, −95, −90} dBm.
  • Q-learning 보상 27개/분할: HO 비용 1 고정, 핑퐁 {1, 3, 9}, 약전계 {2, 5, 15}, 신호 차이 {0.03, 0.1, 0.3}. 탐색 15 epoch, 최종 60 epoch.
  • 신경망은 Q 검증 상위 3개 보상을 공유합니다. DQN·DQN+GRU·PPO는 각 3개, CQL은 보수 계수 {0.1, 1}까지 6개/분할입니다. 탐색 13 epoch, 최종 40 epoch. 전체 후보 수는 동일하지 않습니다.
  • 최종 정책 시드 {0, 1, 2}. GRU 예측기는 분할마다 시드 1개·15 epoch로 고정하므로 GRU 자체의 시드 불확실성은 별도로 추정하지 않았습니다.
  • TTT=1행, 상태 구간, 네트워크 크기와 학습률은 고정했습니다. 이번 결과는 이 범위의 탐색이며 전역 최적화가 아닙니다.

04 / MODEL & ENVIRONMENT

정책 학습에서 실제로 계산한 것

공통 재생 환경

관측된 서빙·이웃 신호만 시간순으로 재생합니다. 같은 주파수의 이웃이 최소 3 dB 강한 신선한 행에서 보류/이동 중 하나를 고릅니다. 셀이 목록에서 사라지면 실제 서빙 셀로 강제 이동합니다.

보상 = −HO −wpp·핑퐁 −wweak·약전계 −wgap·min(최강 셀 차이, 15 dB). 행마다 신호 비용을 누적하며, 강제 이동도 HO·핑퐁 비용에 포함합니다.

할인과 상태

결정 시점 사이의 행별 보상을 γ=0.99로 누적하고, 다음 상태 값에는 γ경과 행 수를 곱합니다. 세션 종료 시 다음 상태 값은 0입니다. 기존 Q 코드의 추가 할인 한 번을 없앴고, γ도 기존 0.9에서 변경했으므로 이전 결과와 차이가 모델만의 효과는 아닙니다.

표 Q 상태는 RSRP 4구간 × 이웃 차이 3구간 × 복귀 2 × 체류 3 = 72개입니다.

모델별 구현

  • DQN: 은닉 64·64 tanh MLP, Double-DQN 목표, 경험 재생 최대 50,000개, 2 epoch마다 목표망 동기화. Adam 3×10⁻⁴, Huber 손실, gradient clip 5.
  • PPO: 같은 크기의 정책·가치망, clip 0.2, GAE λ=0.95, entropy 0.01, 가치 손실 계수 0.5, epoch당 4회 업데이트. 재생 환경 안에서 새 행동을 샘플링합니다.
  • CQL: DQN 손실에 α·[logsumexp Q(s,·) − Q(s,a)]를 더합니다. 학습 세션에 세 가지 규칙과 15% 무작위 행동을 적용해 만든 버퍼를 고정하고, 이후 새 경험을 수집하지 않습니다. 실제 망의 오프라인 RL 검증과 구분해야 합니다.
  • DQN + GRU: 직전 12행의 관측 서빙 RSRP와 동결 마스크로 10초 뒤 관측 서빙 신호 변화량을 예측합니다. GRU 은닉 16, Adam 0.002, L1 손실. 입력은 과거 방향 채움만 하며 예측 대상 행은 10~12.5초 뒤·신선한 관측만 씁니다.

신경망 상태는 서빙 RSRP, 이웃 차이, 복귀 여부, 체류 시간, 최근 30초 HO 수, 이동수단 one-hot, 직전 판단 행 대비 신호 변화, GRU 예측값의 10개 슬롯입니다. GRU 비교 이외 모델은 마지막 슬롯을 0으로 둡니다. GRU는 실제 관측 서빙 신호를 예측하므로 가상 정책이 유지한 셀의 미래를 예측하는 모델로 해석하면 안 됩니다.

  • 한 모델이 일반적으로 우수하다는 주장.

  2. 관측과 셀 식별 한계: (EARFCN, PCI)는 넓은 지역에서 재사용될 수 있습니다. 가상 서빙 셀의 누락은 강제 이동을 만들고, 정책별 강제 이동 수가 달라집니다. 실제 망의 반응·부하·간섭 변화는 없습니다.
